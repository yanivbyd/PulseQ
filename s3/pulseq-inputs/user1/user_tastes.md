# User Taste Profile

This user is a senior, principal, or staff backend and infrastructure engineer.

## Preferred Topics

Aim for a roughly even balance across these two categories:

### Category 1: AI, Agents, LLM, Skills (50%)
- AI engineering: agents, LLM internals, RAG pipelines, vector databases, MCP (Model Context Protocol), MCP UI, tool use, AI coding assistants, AI skills/workflows
- How AI systems work internally, agent orchestration, prompt engineering, fine-tuning, inference optimization

### Category 2: Infrastructure (50%)
- Backend and infrastructure: databases, distributed systems, networking, storage, Linux, cloud infrastructure
- How things work internally (e.g. "How Kafka Stores Messages", "How Linux Handles Memory Pressure")

Both categories favor: deep dives into trade-offs, failure modes, and real-world design decisions.

## Avoid

Frontend frameworks, marketing content, career advice, AI hype without technical substance.
